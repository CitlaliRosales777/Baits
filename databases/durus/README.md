# Preparación conceptual para Durus

No se implementa un backend Durus en esta entrega. Para una práctica futura, el modelo relacional podría representarse por alcanzabilidad como `Usuario -> EventosEmocionales` y `Usuario -> Tratamientos -> Tomas`, usando objetos persistentes y datos sintéticos.

Durus no implementa ODL ni OQL como estándares nativos. Las clases Python serían una analogía de definición de objetos y los recorridos/filtrados una analogía de consulta, diferencia que debe declararse en la demostración académica.

Pendiente de otro trabajo autorizado: seleccionar versión, crear entorno virtual, definir clases, probar `commit/abort`, reapertura y concurrencia. No se afirma ninguna ejecución ni se versionan archivos `*.durus`.
